# 🏥 Healthcare Analytics Dashboard

An interactive **Healthcare Analytics Dashboard** built using **Power BI** to analyze patient demographics, hospital visits, diagnosis trends, laboratory results, doctor performance, and treatment costs. The dashboard helps healthcare professionals make data-driven decisions by providing meaningful insights through interactive visualizations.

---

## 📌 Project Overview

The Healthcare Analytics Dashboard provides a comprehensive view of healthcare data, enabling users to monitor hospital performance, patient trends, doctor workload, and treatment-related insights.

The dashboard allows filtering by **State**, **Blood Group**, and **Year**, making it easy to perform detailed analysis across multiple dimensions.

---

## 🎯 Objectives

- Analyze patient demographics and hospital visits.
- Track patient visit trends over time.
- Identify the most common diagnosed medical conditions.
- Monitor doctor workload and patient distribution.
- Analyze laboratory test results.
- Compare treatment costs across different diagnoses.
- Build an interactive dashboard for healthcare decision-making.

## 📈 Key Insights

- Around **10,000 patients** and **10,000 visits** were analyzed.
- Average patient age is approximately **49 years**.
- Follow-up rate is nearly **50%**.
- Doctor workload averages **10 patients per doctor**.
- Abnormal laboratory results account for approximately **34%** of total tests.
- Migraine, Hypertension, Asthma, Diabetes, and Healthy Checkups are among the most common diagnoses.
- Treatment costs are fairly balanced across major diagnosis categories.
